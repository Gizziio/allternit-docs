# Welcome to Allternit

Allternit is a **local-first agent runtime** that runs AI agents entirely on your machine. No data leaves your computer unless you explicitly configure external providers.

## What is Allternit?

Allternit provides the infrastructure for building, running, and orchestrating AI agents:

- **🤖 Gizzi Runtime** — Execute agents locally with full sandboxing
- **💬 Communication** — Message bus for agent-to-agent coordination  
- **🌿 Git DAG** — Version control for agent workflows
- **🛠️ Skills** — Extensible capability system

## Quick Start

Install Gizzi Code in one command:

```bash
curl -fsSL https://install.gizziio.com/install | bash
```

Then create your first agent:

```typescript
import { AllternitClient } from "@allternit/sdk";

const client = new AllternitClient();

await client.run({
  agent: "hello-world",
  input: "What's the weather?"
});
```
