# Desktop

Native desktop application for Allternit.

## Features

- Visual workflow editor
- Agent monitoring dashboard
- Real-time logs
- Git history browser

## Download

Available for macOS, Windows, and Linux.

```bash
# macOS
brew install --cask allternit

# Or download directly
curl -O https://allternit.com/download/desktop-macos.dmg
```

## Setup

1. Install Gizzi Code
2. Launch Allternit Desktop
3. Connect to your project
