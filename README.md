# Allternit Documentation

Official documentation website for the **Allternit** platform.

## Overview

This repository contains the standalone documentation site for Allternit. It is built with Vite + React + Tailwind CSS and deployed independently.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
