# Browser Extension

Use Allternit directly in your browser.

## Features

- Context menu integration
- Page analysis with agents
- Quick actions
- Screenshot to agent

## Installation

### Chrome

```
Chrome Web Store → Search "Allternit" → Add to Chrome
```

### Firefox

```
Firefox Add-ons → Search "Allternit" → Add
```

## Usage

Right-click on any page element:

- **Analyze** — Send to agent for analysis
- **Summarize** — Get a summary
- **Extract** — Pull structured data
