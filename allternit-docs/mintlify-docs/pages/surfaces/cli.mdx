# CLI

The Allternit CLI (`gizzi`) provides full control from the terminal.

## Global Commands

```bash
gizzi --version      # Show version
gizzi --help         # Show help
gizzi doctor         # Check setup
```

## Project Commands

```bash
gizzi init           # Initialize project
gizzi run            # Run agent
gizzi build          # Build for production
gizzi dev            # Development server
```

## Management Commands

```bash
gizzi config         # Manage config
gizzi skill          # Manage skills
gizzi logs           # View logs
```
