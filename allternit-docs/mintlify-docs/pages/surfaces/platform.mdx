# Platform

Team collaboration and cloud features.

## Features

- Shared agent repositories
- Team permissions
- Usage analytics
- Managed compute

## Getting Access

Platform is in private beta. Request access:

```bash
gizzi platform signup --waitlist
```

## Self-Hosted

Deploy your own platform instance:

```bash
docker run -p 8080:8080 allternit/platform
```
