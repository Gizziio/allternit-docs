# Installation

## macOS / Linux

One-line installer:

```bash
curl -fsSL https://install.gizziio.com/install | bash
```

Or with wget:

```bash
wget -qO- https://install.gizziio.com/install | bash
```

## Windows

PowerShell:

```powershell
irm https://install.gizziio.com/install.ps1 | iex
```

## npm

```bash
npm install -g @gizzi/gizzi-code
```

## Verify Installation

```bash
gizzi --version
# gizzi 0.1.0
```
