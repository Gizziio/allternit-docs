## Writing Tips for Allternit Blog Posts

### Voice and Tone
- **Professional but approachable:** Avoid jargon, explain technical terms
- **Humble:** Acknowledge limitations and uncertainty
- **Transparent:** Share methodology, including failures
- **Mission-aligned:** Connect to beneficial AI and safety

### Structure
- Use descriptive headers (H2, H3) to organize content
- Keep paragraphs short (3-4 sentences max)
- Use bullet points and numbered lists for scannability
- Include visuals (figures, diagrams, code examples)

### Technical Content
- Explain acronyms on first use
- Link to relevant documentation
- Provide code examples where applicable
- Test all links before publishing

### Accessibility
- Use descriptive alt text for all images
- Ensure sufficient color contrast
- Provide transcripts for videos
- Use semantic HTML structure

### Length
- Typical length: 800-2,000 words
- Reading time: 5-10 minutes
- Can be shorter for announcements, longer for deep dives

### Review Checklist
Before submitting for review:
- [ ] Spell-checked
- [ ] Technical accuracy verified
- [ ] All links tested
- [ ] Images optimized
- [ ] Alt text added
- [ ] Citation format checked
- [ ] Author bio included
- [ ] Social media summary prepared
